# TP Supabase (Flutter)

Application Android du TP : authentification Supabase, clients et cache local
Hive, carte OpenStreetMap, liens externes, photos, scan de documents/PDF, QR
codes et grille de données.

## Ouvrir et lancer

Ouvrir **ce dossier `tpsupabase`** dans Android Studio (il contient
`pubspec.yaml`), puis sélectionner le SDK Flutter :

```text
C:\Users\edemo\development\flutter
```

Le SDK Dart à utiliser est celui inclus dans Flutter :

```text
C:\Users\edemo\development\flutter\bin\cache\dart-sdk
```

Dans un terminal PowerShell ouvert dans ce dossier, fournir l’URL de votre
projet Supabase et sa clé publique `publishable` (ou sa clé `anon` historique),
puis lancer l’application :

```powershell
flutter pub get
flutter run --dart-define=SUPABASE_URL=https://VOTRE-PROJET.supabase.co --dart-define=SUPABASE_PUBLISHABLE_KEY=VOTRE_CLE_PUBLIQUE
# ou, pour les projets historiques :
# flutter run --dart-define=SUPABASE_URL=https://VOTRE-PROJET.supabase.co --dart-define=SUPABASE_ANON_KEY=VOTRE_CLE_ANON
```

Pour démarrer avec le bouton **Run** d’Android Studio, ajoutez les mêmes deux
options dans **Run > Edit Configurations > Additional run args**.

Ne mettez jamais de clé `service_role` dans l’application mobile. Sans
configuration Supabase, l’écran de connexion explique comment configurer le
projet et désactive le bouton de connexion.

## Base Supabase

Dans le SQL Editor du projet, créez les tables et la relation utilisées par
l’application :

```sql
create table if not exists public.adresse (
  id bigint generated by default as identity primary key,
  rue text not null,
  codepostal text not null,
  ville text not null
);

create table if not exists public.client (
  id bigint generated by default as identity primary key,
  prenom text not null,
  nom text not null,
  tel text not null,
  email text,
  id_adresse bigint not null references public.adresse(id)
);

alter table public.adresse enable row level security;
alter table public.client enable row level security;

create policy "Les utilisateurs authentifiés lisent les adresses"
  on public.adresse for select to authenticated using (true);
create policy "Les utilisateurs authentifiés lisent les clients"
  on public.client for select to authenticated using (true);
```

Ajoutez des adresses puis des clients liés par `id_adresse`, et créez un
utilisateur email/mot de passe dans **Authentication > Users**. Les politiques
autorisent uniquement la lecture après authentification. Supabase doit exposer
la relation `client.id_adresse -> adresse.id` pour que la jointure imbriquée
fonctionne.

Exemple d’insertion d’un client avec son adresse liée :

```sql
with new_address as (
  insert into public.adresse (rue, codepostal, ville)
  values ('1 rue de Bretagne', '56000', 'Vannes')
  returning id
)
insert into public.client (prenom, nom, tel, email, id_adresse)
select 'Alex', 'Martin', '0600000000', 'alex@example.com', id
from new_address;
```

## Android

Le manifeste déclare Internet, la caméra et les schémas d’applications externes.
La galerie utilise le sélecteur système Android. Le scan de documents, le QR
code et l’aperçu PDF requièrent un appareil ou un émulateur Android avec caméra.
OpenStreetMap requiert une connexion Internet.
